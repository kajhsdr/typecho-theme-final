# typecho-theme-final

经常换主题是不好的事情。但是如果你需要，可以试试我这款。

### 介绍

这是我业余时间做出来的，很简单简洁。如果CSS和HTML压缩之后，页面可以到2K以内。

使用本主题，不需要声明主题来源，不保留任何权限。

并且我认为final应该是结构最简单的Typecho主题了，所以修改成本很低，有什么问题可以直接提issue，或者你可以试试自己修改。
